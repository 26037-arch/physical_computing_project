## 공통 규칙

- **지금 상태 가정**: 외곽선과 칼로 따는 창(파랑)은 재단 때 끝냈고, 드릴 구멍(빨강 십자)은 송곳 자국만 있다고 본다. 이미 뚫은 구멍은 해당 단계에서 M3 볼트를 핀으로 꽂아 맞춘다.
- 지그 없이: 각도는 종이 각도자(20°·45°·65.1°), 틈은 큐브에 감은 마스킹테이프(기둥 59.0, 후드 60.0), 직각은 직각자·유리판, 위치는 자로 잰 연필 선.
- 드릴은 송곳 자국 → Ø2 → 표기 지름. 같은 자리 구멍을 가진 판 여러 장은 붙이거나 겹친 뒤 한 번에 관통한다.
- 순간접착제는 겔형. 구멍·나사산·슬롯 둘레 2 mm 에는 바르지 않는다(R9). 돌아가거나 빼야 하는 곳 근처를 붙일 땐 볼트를 먼저 꽂아 두고 붙인다.
- 돌아가거나 빼야 하는 곳(모터·서보·힌지·리프터 핀·홀더–커플링)은 관통 볼트 + 너트 + 와셔. 멈춤나사·힌지 너트에는 순간접착 금지.
- 볼트는 손으로 끝까지 → 공구로 조금. 포맥스가 하얗게 눌리면 과조임이다.
- 칼질은 쇠자에 대고 3~4번. 사포는 유리판 위 180방 → 320방.
- 방향: 오른쪽 = +x = MG996R 쪽, 왼쪽 = −x = SG90 쪽, 앞 = +y = 관중·패널 쪽, 뒤 = −y = 타워·힌지 쪽 (로봇이 바라보는 방향 기준 — 로봇 앞에 서서 보면 로봇의 오른쪽이 내 왼손 쪽).
- '종이 본 면' = 재단 가이드 종이를 붙였던 면. 타워·팔·끝판(YZ 조각)은 이 면이 모두 +x(오른쪽)를 보게 놓인다.
- 지그를 출력하지 않았으므로 9절 R12(지그 출력 오차)·R15(지그가 부품처럼 보임)는 해당 없음.

## 화면(3D) 규칙

- `from`: 조각·부품이 최종 자리에서 from 만큼 떨어진 곳에서 출발해 제자리로 들어온다 (월드 mm, Z 위, +Y 앞, X = 로봇 오른쪽). 후드 조각은 assembly_web.json 의 OPEN(60°) 자세 기준. add 가 빈 단계의 from 은 쓰지 않는다.
- `join`: `glue` = 순간접착, `bolt` = 볼트·너트 체결, `place` = 놓기·끼우기, `drill` = 뚫기·깎기·표시 (공구 가공), `check` = 손 시험·재기
- `view`: front = 앞(+Y)에서, back = 뒤(−Y)에서, left = 로봇 왼쪽(−X, SG90 쪽)에서, right = 로봇 오른쪽(+X, MG996R 쪽)에서, top = 위에서, iso = 앞·오른쪽 위, iso-back = 뒤·왼쪽 위.
- 작업대 단계: 작업대에서 하는 단계(기둥·띠 쌓기, B02·모터, 타워 묶음, 리프터, 후드 몸통, B10·SG90·크랭크)도 화면에는 조각이 최종 자리에 나타난다.
- 이름: 인스턴스 이름은 models/robot_v5h/assembly_web.json 과 같다. P01#1~5 앞오른쪽(+x+y), #6~10 앞왼쪽, #11~15 뒤왼쪽, #16~20 뒤오른쪽 모서리(각 1→5 층 아래→위). P02-Lk#j 의 j: 1 앞 변 +x 쪽, 2 앞 변 −x 쪽, 3 왼 변 +y 쪽, 4 왼 변 −y 쪽, 5 뒤 변 −x 쪽, 6 뒤 변 +x 쪽, 7 오른 변 −y 쪽, 8 오른 변 +y 쪽. H02#1 = HD1(판 바로 밑), H02#2 = HD2. B06#1 = T1L(안쪽), B06#2 = T2L. K03#1·L03#1 = 오른쪽, K03#2·L03#2 = 왼쪽. L01#1~5 = −x → +x. F02#1·2 = 커플링 위 멈춤나사, #3·4 = 아래. F07#1 = MG996R 혼 중심나사, F07#2 = SG90. F08#1 = 오른쪽 B 핀, F08#2 = 오른쪽 F 핀, F08L#1 = 왼쪽 B 핀(링크), F08#3 = 왼쪽 F 핀.
- 1단계의 `focus` 는 아직 나타나지 않은 `H01#1` 자리다(카메라 위치용).

## 부록 D — 확인 필요 모음

- 43. 모터 + B02 를 세 벽 위에 얹기 — 확인 필요(문서 5.0절에 없는 순서): 커넥터가 몸통 옆으로 약 5 mm 나와 데크 창(±22)으로도, 막힌 옆벽으로도 지나가지 못한다 — 그래서 오른쪽 옆벽을 모터 뒤에 붙인다. 접착제는 벽 윗모서리에만(모터 쪽으로 흐르지 않게).
- 61. 끝판 L03 두 장 겹쳐 핀 구멍 뚫기 — 원래는 조립 뒤 지그 4D 로 뚫는 구멍이다 — 두 장을 함께 뚫어 좌우 핀 높이를 같게 한다. 구멍–홈 거리 오차(종이 본 ±0.3)가 그대로 갈고리 높이 오차가 된다(확인 필요). L03 은 위아래·앞뒤 대칭이라 방향은 상관없다.
- 73. 팔 K04 두 장 겹쳐 힌지 뚫기 — 두 팔 힌지 구멍이 같은 자리여야 후드가 비틀리지 않고 돈다(지그 3b·4E 대신). 혼 구멍은 실물 원형 혼을 힌지 구멍에 동심으로 대고 혼 구멍을 송곳으로 옮겨 찍는 게 정확하다(반경 7 은 가정, 확인 필요).
- 77. 원형 혼을 오른팔에 (F06 M2 ×4) — 혼 구멍이 M3 탭이면 M3×8 로 바꾼다(F06). 중심나사 머리가 혼 면 안으로 들어가지 않으면 혼이 들뜬다(확인 필요). 와셔 심이 혼 원판 위치를 정해 T1R 과 틈 0.5 를 만든다(R14).
- 80. 후드를 타워 사이에 넣어 혼 끼우기 — 서보 각 = 후드 각 + 15° (CLOSE 15 / OPEN 75 / FLIP 105 / LOAD 135). 전원 없이 가운데는 짐작일 뿐이다 — 배선 뒤 서보를 75° 로 보내 후드가 60° 인지 보고, 틀리면 F04·중심나사를 풀어 톱니를 옮긴다(확인 필요). 왼쪽으로 비킬 여유는 약 2.5 mm 뿐이니 비스듬히 넣는다.
- 81. 원형 혼 중심나사 (F07) — 문서(2.3절)는 '팔의 Ø3.2 구멍으로 드라이버'라고만 한다 — 두 팔 사이(약 60 mm)에는 드라이버가 들어가지 않으므로 이 길을 쓴다(확인 필요). 드라이버가 곧게 들어가면 왼쪽 힌지와 혼이 한 축이라는 뜻이다.
- 87. SG90 판 B10 두 장 붙이기 (작업대) — 확인 필요(문서 5.0절에 없는 순서): 크랭크 바깥면이 타워에서 4 mm 라 B10 을 붙인 뒤에는 SG90 혼 중심나사에 드라이버가 안 들어간다 — 그래서 SG90 과 크랭크를 작업대에서 먼저 단다.
- 92. 크랭크를 SG90 축에 (F07 중심나사) — 서보 0° = 크랭크가 슬롯 쪽 사점 = 리프터 최하. 전원 없이는 0° 끝을 모른다 — 서보 테스터나 아두이노로 0° 를 먼저 보내 두기를 권장(배선 범위, 확인 필요). 크랭크는 0° → 90°(앞·위) → 180°(뒤·위)로 돌아야 하고, 반대로 돌면 B11 을 친다. 이 나사는 B10 을 타워에 붙인 뒤엔 못 푼다.
- 96. 크랭크 핀 (F09 M3×6) — 끝이 링크 안쪽면을 넘으면 타워를 긁는다 — M3×6 만(없으면 M3×8 + 머리 밑 와셔 3장). 크랭크는 볼트 위에서 돌고 볼트·링크는 함께 움직인다. 구멍이 안 맞으면 크랭크 톱니 위치가 틀린 것이다(확인 필요).
- 99. 패널 앞판 C01 구멍·20° 깎기 — LCD 구멍 간격 75 × 31 은 가정이다 — 실물 LCD 를 대고 송곳으로 찍는 게 정확하다(확인 필요). LCD 고정(F12: M3×12 + 너트 2 + 와셔)은 배선 단계에서.
- 102. 버튼 받침 C04 — 택트 스위치는 배선 단계에서 C01 앞에서 구멍에 넣어 C04 에 붙인다 — 스위치 다리를 빼는 길은 확인 필요. LCD·버튼·배선은 이 설명서 범위 밖이다.
