## 병합 시 유지한 경계

- 구동부는 원격의 P30/좁은 허브·6 mm 막대·원뿔 핀을 쓴다. P07은D에만1개,
  P30은측면에4개다. 소켓 깊이6, 핀 삽입4.8, J03 두께9.8을 함께 적용한다.
- 코어와 U/D 센터 사이의8×8 키는 잠금 막대와 다른 부위다. 그 키를6 mm로
  줄이지 않는다. 막대 가이드6.3, 막대 캐리지6.1, J02 6.2/6.3/6.4는 새 막대용이다.
- 깊어진 머리 자리에 맞춰 U/D 센터 나사는 M3×10을 채택한다.
  머리 받침면18.5에서 인서트 입구11까지7.5를 지나2.5 mm 물린다.
  기존 M3×14는 막힌 파일럿 끝5.5를 지나므로 사용하지 않는다. 회전 반력은
  8×8 키가 받고 나사는 센터를 축방향으로 유지한다. 일반 센터 M3×16은 그대로다.
- 서보 받침과 레일 지지대는 Rev B의 실제 맞댐 면·키·M5 세 체결점을 유지한다.
  측면과 D가 같은 P14를 쓰며 잠금 서보 P25는 M04 체결을 유지한다.
- 풀이기/기구 제어 JS와 C++ 및 행정 상수는 원격 최신과 동일하다. 화면에서는
  최신 구동부를 유지하고 Rev B 출력 오프셋과 레일 위치만 결합한다.
- STEP/STL·내장 모델·PNG·PDF·CSV·ZIP은 소스 충돌 선택으로 끝내지 않고
  통합 CAD에서 다시 생성한다. 같은 파일명의 이전 판을 섞지 않는다.

## 제작 파일과 검증

현재 부품은33종93개(시험편/지그 포함), 첫 장 번호61개다. P01~P28 및P30은
본체89개, P29는1개, J01~J03은3개다. M3 인서트69/M4 인서트14이며
F17/F18은수량0, F11은32세트, F25는5세트다. 패드 수는 측면8개+D4개=12개다.

전체 검사에서는 기존 큐브36회전·뒤집기13자세·모듈3자세에 더해
F/R/D층 회전20자세를 결합된 주변 헤드와 비교한다. 새 원뿔 핀 포획 샘플과
잠금 막대/실제 M3머리 외형의 축방향 여유도 검사한다. 고정부는47개 검사 그룹에
맞댐 면·M5머리/와셔·MGN 블록·인서트 뒤 나사 끝과 U/D 센터 나사를 포함한다.

`models/robot_v4/assembly_kit/merge_comparison_checks.json`에는 구형50×50 측면
판과 새 띠 판을 같은 D층 코너45° 자세에 대입한 비교를 기록한다. 이 표본에서
구형 판은589.96 mm³가 겹쳤고 통합판은0이었다. 이는 한 자세의 비교이며
전체 동작에 대한 보증은 아니다. 전체 결과는
`mechanical_checks.json`, `kit_checks.json`, `mesh_checks.json`, `pdf_checks.json`을
확인한다. 배포 ZIP은 SHA256 목록으로 실제 포함 파일의 일치를 검증한다.

최종 검사 결과: 본체 실패0(큐브36/뒤집기13/주변 헤드와 층 회전20/핀 포획4/
모듈3자세), 고정부47그룹 실패0, 출력33종93개 메시 통과다. U/D M3×10은
양쪽 모두 간섭0이며, 기존 M3×14는 코어와각10.308 mm³가 겹쳐 배제했다.
시뮬레이터에 내장한29개 STL과 파라미터는 최종 CAD와 바이트가 일치한다.
PDF는41쪽·첫 장61개 번호이며 글꼴/텍스트 경계와 부품표를 함께 검사한다.

실물 시험은 아직 하지 않았다. 한 모듈부터 출력해 무부하 이송20회, 핀/막대
재진입, 같은 토크에서 코어의 각변위,6면 회전, 왕복 뒤집기20회를 순서대로
시험한다. 뒤집기에서 가운데 층이 마찰로 따라오는 가정은 계속 남아 있다.
실물에서 미끄러짐·층 지연·인서트 들뜸이 생기면 자동 풀이 운전을 승인하지 않는다.
