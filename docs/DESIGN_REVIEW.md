# 3D 출력 부품 설계 검토 (Codex 리뷰 → 반영)

검토 대상: [fusion/scripts/cube_robot_parts.py](../fusion/scripts/cube_robot_parts.py), `models/*.stl` (1차 생성본).
검토 방식: Codex 플러그인(읽기 전용)에게 NEMA17·큐브 캡 실물 치수, PLA 출력 강도, Fusion API 형상 처리를 점검하게 했다.
아래 "지적"은 Codex 리뷰 요약이고, "반영"은 그 뒤 스크립트에 적용한 내용이다.

## 1차 설계 (검토 전)

| 부품 | 치수 | 부피 |
|---|---|---|
| center_coupler | Ø16 × 22 + 십자 키 12×3×5 (총 27 mm) | 4.41 cm³ |
| center_cap | Ø15.6 × 6, 십자 슬롯 12.3×3.3×4 깊이, 핀 Ø4×3 | 0.90 cm³ |
| motor_mount | 42.3×42.3×4 판 + 발판 14 mm | 7.72 cm³ |

## 지적 사항과 반영

| # | Codex 지적 (수치) | 반영 |
|---|---|---|
| 1 | 십자 키 높이 5 mm > 슬롯 깊이 4 mm → 커플러 어깨와 캡 윗면 사이 **1 mm 틈**, 축 방향 기준면이 없음 | `KEY_H 5.0 → 3.5`: 어깨가 캡 윗면에 닿고 슬롯 바닥에 0.5 mm 여유 |
| 2 | 12 mm 키가 Ø15.6 캡에 들어가면 슬롯 끝과 외벽 사이 최소 두께 **≈1.43 mm** (PLA 토크 0.4 N·m, 반경 6 mm에서 접선력 ≈ 67 N) | `KEY_W 12 → 10`, `KEY_T 3 → 4`: 슬롯 10.3×4.3, 캡 최소 외벽 ≈ 2.2 mm, 키 팔 두께 33 % 증가 |
| 3 | M3 세트스크류용 **Ø3.0 무나사 구멍은 체결력 없음** | `SETSCREW_D 3.0 → 2.5` (출력 후 M3 탭 가공). 반복 체결이 필요하면 Ø3.4 관통 + 너트 포켓으로 바꿀 것 |
| 4 | 브래킷 발판(y = −21.15…−17.15)이 아래쪽 모터 홀(y = −15.5, r = 1.7)을 **0.05 mm 침범**, 나사 머리 공간 부족 | `MOUNT_W = 48` 신설(판 폭 42.3 → 48): 발판 안쪽과 홀 중심 간격 4.5 mm |
| 5 | 축 공차 0.2 mm(편측 0.1), 키 공차 0.3 mm(편측 0.15)는 시험 출력 시작값으로 적절. 캡 Ø15.6·핀 Ø4 는 **실물 큐브 센터 실측 전에는 미확정** | 유지. 실물 캡 자리 실측 후 `CAP_D`, `CAP_PEG_D` 조정 (계획서 위험 대책 "공차 시험 출력" → 상수 변경 1줄) |
| 6 | 축 체결 깊이 12 mm = 축 지름의 2.4배로 충분. 보어 바닥 0.5 mm 축방향 여유 권장 | 조립 시 삽입량 11.5 mm 로 운용 (커플러 길이 변경 없음) |
| 7 | 면 위 스케치에 외곽선이 자동 투영되어 "면적이 가장 가까운 프로파일" 선택은 치수 변경에 취약 | 발판은 목표 면적으로, 구멍은 원 면적 ±20 % 로 선택하도록 명시 (스크립트 반영) |
| 8 | 조립 거리: 큐브 면 → 커플러 모터측 끝 = 6 + 22 + 3.5 − 4 = **27.5 → 어깨 접촉 시 28 mm**. 모터 전면 → 큐브 면 = 28 + 축 길이 − 삽입량 ≈ 축 20 mm 기준 **36 mm** | 시뮬레이터(sim/app.js) 배치와 프레임 설계 기준값으로 사용 |

## 출력 권장 (Codex)

- **커플러**: 축 구멍 입구를 베드에, 키를 위로. 0.2 mm 적층, 외벽 4~6, 키 부분 인필 100 %.
- **캡**: 슬롯 면을 베드에, 핀을 위로 (브리징·첫 층 공차 확인).
- **브래킷**: 넓은 장착판을 베드에, 발판을 위로 (서포트 불필요). L자 접합부 리브 추가 검토.

## 남은 확인 (실물 단계)

1. 사용할 3×3 큐브의 센터 캡 지름·깊이·조절나사 공간 실측 → `CAP_D`, `CAP_PEG_D`, `CAP_PEG_H`.
2. 구매한 NEMA17 의 축 길이(15~24 mm)·D컷 길이 → 삽입량과 세트스크류 위치 `SETSCREW_Z` 일치 확인.
3. 한 면만 조립해 토크 전달(핀이 헛도는지)을 먼저 확인 — 계획서 9주차 "모터 1개 구동 시험"과 같은 단계.
