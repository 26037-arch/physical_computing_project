# 3×3 큐브 풀이 로봇 프로젝트 보고서

> **V5 하루 제작판 (2026-10-24, `v5/`)**: 이 보고서는 V4 Rev D 기준이다. 시중 큐브 + 기울어진 컵 + 후드 + 리프터의 V5 는 [REPORT_V5.md](REPORT_V5.md)·[HARDWARE_V5.md](HARDWARE_V5.md)·[BUILD_V5.md](BUILD_V5.md)에 있고 펌웨어·시뮬레이터·시나리오는 `v5/` 아래에 있다. 두 버전은 같은 풀이기(CFOP)를 쓰되 운전 방식(5면 vs 6면 재배향)이 다르다.

## 1. 프로젝트 개요와 현재 상태

이 프로젝트는 Arduino가 큐브 상태를 기록하고, 보드 안에서 풀이 수열을 계산한 뒤 다섯 개의 모터로 큐브를 맞추는 로봇이다. 현재 설계는 측면2핀 헤드4개와 아래 중공축 헤드1개, 코어를 고정하는 승강 잠금 막대, 자동 이송 서보로 구성한다. 큐브는 위로 넣고 뺀다.

현재 결과는 CAD 시제품, 펌웨어, 웹 시뮬레이터와 제작 문서다. 알고리즘과 실제 C++ 코드의 호스트 시험, 두 Arduino 보드의 컴파일, 이산 CAD 간섭 검사를 수행했다. 실물 출력·조립·부하 시험은 아직 하지 않았다. 이번 세션에서 Wokwi 시나리오는 생성했지만 Wokwi 실행은 하지 않았다.

이전6모터 직결 구조와 뒤집기 운전은 설계 이력이다. 본 보고서는 Rev D의5면 운전을 기준으로 하며, 이전 보고서에서 인용한 Wokwi 성공·실행 시간은 현재 구조의 시험 결과로 재사용하지 않는다.

## 2. 목표와 성공 기준

| 목표 | 현재 구현 | 아직 필요한 확인 |
|---|---|---|
| 스스로 섞고 풀기 | 로봇이20수 섞고 수열을 기록, 보드 내 CFOP 계산 | 실제 큐브5회 연속 성공 |
| 열린 상부와 쉬운 조립 | 5헤드·승강 막대, 공통 레일/서보 받침,3점 체결·지그 | 출력 공차·조립 시간·반복 정렬 |
| 단계별 오류 중단 | 결합/후퇴12접점, 새 지지 확인 후 전환, 실패한 수는 미반영 | 실제 배선·스위치·끼임 시험 |
| 같은 알고리즘 사용 | JS/C++의 탐색 순서·수열·절차 교차 비교 | 실제 보드의 센서·모터 동작 |
| 빠른 풀이 | 보수적 가감속·720ms 이송 | 30초 목표 미달성, 실측·최적화 필요 |

사용자가 손으로 임의로 섞은 큐브의 색을 읽는 기능은 현재 없다. 일반6면으로 섞인 상태를 소프트웨어 풀이기는 풀지만, 실물 장치는 그 초기 상태를 먼저 알아야 한다. 현재 시연 경로는 맞춘 큐브를 올리고 로봇이 직접 섞는 방식이다.

## 3. 피지컬 컴퓨팅 구성

입력은 버튼1개, 시리얼 명령, 독립 끝 센서12개다. Arduino는 큐브 내부 상태·CFOP 탐색·장착과 지지 전환 절차를 처리한다. 출력은 NEMA17/A4988 다섯 쌍, MG996R 여섯 개, LCD1602와 부저다. 실물 기본 보드는 UNO R4 WiFi이고, UNO R3는 호환 컴파일·시뮬레이션 대상으로 유지한다.

| 부품/장치 | 수량 | 역할 |
|---|---|---|
| NEMA17+A4988 | 5쌍 | 측면4개와 아래면 회전 |
| MG996R | 6 | FB/RL/D/LOCK의4개 신호로 이송 |
| 74HC165 | 2 | 결합6개·후퇴6개 접점을 독립 입력 |
| 긴 레버 마이크로스위치 | 12 | 각 모듈의 양 끝 도달 확인 |
| 강재 사각 막대 | 6×6×230mm | 코어 회전 억제, 배출 시30mm 후퇴 |
| 레일/블록 | 5세트 | 회전 헤드의24mm 직선 이송 |
| 출력 부품 | 33종93개 | 큐브·헤드·받침·조립 지그 포함 |

사진 속 키트에서는 LCD1602/I2C, 택트 버튼, 부저와 점퍼선을 확인해 재사용한다. 사진의 소형 서보·28BYJ-48·ULN2003은 본 구동계를 대체하지 않는다. 74HC595는 출력용이므로74HC165 입력 회로를 대신할 수 없다. 정확한 구매·출력·재사용 번호와 수량은 제작 PDF 및 부품 CSV가 기준이다. 실제 구매 단가는 확보하지 않아 총비용을 임의로 산정하지 않았다.

## 4. 현재 기구와 조립 설계

57mm 도넛 큐브의 측면은16×50mm 띠 구동판과 원뿔 끝 Ø3 핀 두 개로 구동한다. 띠 형태는 아래 층 코너의 회전 경로를 비워 준다. 아래 D헤드는50×50mm 구동판, 중공축과1:1 벨트를 사용해 잠금 막대가 중앙을 지나갈 수 있게 한다.

잠금 막대는6.4mm 사각 소켓에4mm 들어가고 소켓 바닥/나사 머리와1mm 축방향 여유를 둔다. 코어와 U/D 센터의 사각 연결은 회전을 억제한다. 서보 크랭크 반지름은 헤드12mm, 막대15mm이며 링크36mm로 각각24/30mm를 이송한다.

조립 기준은 프레임 직각→공통 받침→레일 위치 결정 턱→지그를 이용한 핀 깊이·중심 정렬이다. 서보 받침은 프로파일에3점 체결해 길이가 제각각인 전산봉/간격관 조정을 줄인다. 나사는 고정과 하중 전달에, 턱과 지그는 위치 반복에 사용한다. 마이크로스위치 몸체를 기계 스토퍼로 사용하지 않는다.

## 5. 물리 검토에서 바꾼 부분

| 발견 | 판단 근거 | Rev D 반영 |
|---|---|---|
| 전체 뒤집기가 마찰에 의존 | R/L 핀은 바깥층만 구동하고 코어/중앙층을 직접 묶지 않음 | 뒤집기 금지, 상단 고정5면 알고리즘 |
| 직렬 스위치의 후퇴 오판 | 한 접점만 열려도 후퇴로 보임 | 모듈별 결합/후퇴12접점과 입력 칩2개 |
| 스위치와 이동부 간섭 | 기존 전진 몸체가 중간 캐리지와300.523mm³ 겹침 | P13/P29 바깥 받침, 긴 레버만 접촉 |
| 서보의 급격한 지령 | 실제 접근 속도·충격이 불확실 | 1도/4ms, 전체720ms 지령 |
| 사각 잠금 유격 | 6/6.4mm 조합의 한 방향 놀이3.960도 | 실제 막대를 기준으로 맞춤층 시험·전체 강성 측정 공정 |

핀과 막대의 해석은0.10N·m를 시험 기준으로 삼았다. 한 핀 집중 하중은5.236N, Ø3 강철핀의 보수적 외팔보 굽힘은19.36MPa와 끝변위0.00207mm다. 6mm 강재 막대230mm의 계산 비틀림은0.0915도다. 이 값들은 재료 가정에 따른 계산이며, 출력물의 적층 강도나 전체 조립품의 하중 합격을 증명하지 않는다.

맞춤층의 총 평면 간극이0.02~0.04mm라면 소켓 놀이+강재 탄성의 계산값은 최대0.475도다. 경화재·고정부·내부 코어 키의 변형은 별도다. J02 시험편에서 재질·이형·완전 경화·미끄럼을 확인하고 전체 코어의50mm 레버×2N 양방향 시험으로 판단한다. 이 공정의 실물 성능은 아직 검증하지 않았다.

가장 큰 남은 기계 문제는 크랭크 사점의 끼임 힘이다. 이상 강체·서보1N·m 가정에서는5도 위치에서약718N으로 계산된다. 실제 힘은 부품 변형과 마찰 등에 제한되지만 안전 상한을 알 수 없다. 서보 감속과 끝 센서는 힘 제한기가 아니므로, 검증된 탄성/힘 제한 링크와 실물 하중 시험 전에는 무인 운전을 승인할 수 없다.

## 6. 좌표와 허용 동작

풀이기의 논리 면은 U/R/F/D/L/B다. 흰색 U를 아래로 장착한 orient=1을 유지하며, 논리U는 물리 아래D 헤드로 돌린다. 논리D는 헤드 없는 물리 상단이므로 고정한다. 측면과 U의90도·180도·역90도로15개 수를 사용한다. 큐브 상태 모델은 일반18수를 지원해 회귀 입력을 만들 수 있다.

5면만 사용해도 테스트한 일반6면 섞기 상태를 모두 풀었다. 단순히 D가 있는 공식을 실행 중 건너뛰는 방식은 사용하지 않는다. 크로스의 거리표와 탐색부터 허용 수 집합을 맞추고, 마지막층 공식도 D 없는 동등 수열로 생성한다. `M F D R`처럼 금지면이 포함된 입력은 전체를 실행 전에 거부한다.

## 7. 보드 안의 풀이 알고리즘

1. **Cross:** 엣지 위치/방향의 쌍 거리표를 플래시에 저장한다. 여섯 쌍 거리의 최댓값을 허용적 휴리스틱으로 사용하고15수 IDA*로 탐색한다. BFS 전수 검사에서190,080상태 모두 도달하며 최장10수였다.
2. **F2L:** U 회전과 `X U^k X'` 트리거27개를 매크로로 사용한다. 크로스·완료 슬롯을 보존하면서 가장 쉬운 코너/엣지 쌍부터 삽입한다. 관심 쌍의 작은 상태와 거리표로 메모리를 절약한다.
3. **OLL:** 윗층 방향 키를 계산하고 생성한57개 경우 표에서 공식을 찾는다. 유효 방향216상태를 검사한다.
4. **PLL:** 윗층 순열 키와 앞뒤 U 조정으로 공식을 찾는다.87개 표 항목이288순열을 처리한다. OLL/PLL 모두 D 없는 수열이며 마지막층62,208상태를 전수 해결했다.

거리표·공식표는 `tools/gen_tables.js`가 생성한다. C++와 JS의 생성 표를 직접 수정하지 않는다. IDA*는 깊이 우선 탐색의 작은 메모리를 사용하며, 단계 분해로 전체 큐브를 한꺼번에 탐색하는 부담을 줄인다. 최종 풀이 전체가 최단 수열이라는 뜻은 아니다.

## 8. 제어 코드와 오류 처리

실행 흐름은 명령 해석→수열 사전 검사→끝 상태 확인→새 지지 결합→기존 지지 해제→전체 끝 재확인→STEP 출력→내부 상태 갱신이다. 잠금 막대는 장착 중 유지한다. 오류가 나면 해당 수를 돌리지 않고 완료한 수까지의 상태를 유지한다. 예를 들어 F를 완료한 뒤 R 준비가 실패하면 내부 상태에도 F만 반영한다.

핀·서보 각도·720ms 이송·모터 램프·면 매핑은 `config/robot_v4.json`에서 C++/JS 계약으로 함께 생성한다. 형상 치수는 `models/robot_v4/parameters.json`을 사용한다. JS 동작은 펌웨어와 같은 명령 순서·로그·STEP 시간으로 검사한다. 웹 배속은 표시만 바꾼다.

숫자 명령도 점검했다. `Q 2`가 실제 모터 모드를 켜거나 `T 65536`이 잘릴 수 있어 부호·범위 초과·접미 문자를 거부하도록 수정했다. 실제 접점을 읽는 `I` 진단 명령을 추가해12개 스위치를 하나씩 시험할 수 있게 했다. 상세 항목은 `ARDUINO_REVIEW_V4.md`에 기록했다.

## 9. 회로와 전원

| 신호 | Arduino 핀 |
|---|---|
| STEP F/R/B/L/D | D2/D3/D4/D5/D6 |
| 공통 DIR | D7 |
| 서보 FB/RL/D/LOCK | D8/D9/D10/D11 |
| 74HC165 DATA/CP/PL | D12/D13/A0 |
| 버튼/부저 | A2/A3 |
| LCD I2C | A4/A5 |

74HC165의 결합/후퇴 입력은 각각 외부10kΩ 풀업과 NO→GND로 연결한다. 가까운 칩이 결합, 먼 칩이 후퇴이며 F/B/R/L/D/LOCK 순서다. 미사용 입력은 HIGH로 두고 프레임 확인에 사용한다. 칩마다100nF 디커플링을 둔다.

모터12V, 서보6V 전원과 보드 전원을 구분하고 GND를 공통 연결한다. A4988 전류 제한은 실제 모터·드라이버 자료와 발열 시험으로 설정한다. 모터가 동시에 돌지 않아도 유지 전류는 흐르므로 전원 용량을 동시 회전 수만으로 선정하지 않는다. `Q 1`은 전원 차단이나 비상정지가 아니다.

본체 CAD도 층 회전36자세·층/인접 모듈20자세·지지 전환3자세 등을 통과했다. 기존 뒤집기 형상 검사13자세는 이력으로 남지만, 그 통과를 뒤집기 구동의 근거로 사용하지 않는다. 검사는 이산 자세이며 실제 접촉·마찰·재료 시험과 구분한다.

UNO R3 컴파일은 Flash30,926/32,256바이트, 정적RAM1,294/2,048바이트다. UNO R4 WiFi는 Flash81,292/262,144바이트, 정적RAM9,940/32,768바이트다. R3의 잔여754바이트는 스택을 실측한 여유가 아니다. 실제 보드는 R4를 기본으로 한다. R4의 LiquidCrystal I2C 아키텍처 경고가 있어 실제 LCD 시험을 남긴다.

## 11. 속도 목표와 현재 비용

현행 램프에서90도는787.655ms,180도는1,210.305ms이며 정착250ms를 포함한다. 이송은 한 방향720ms+센서 확인 시간이다. 로봇의5면 섞기 시드1 풀이가56수이므로 회전만 모두90도라고 해도약44초다. 여기에 이송·센서 대기·계산 시간이 추가되므로30초 목표를 달성했다고 주장할 수 없다.

속도를 높이기 전에 핀 포착·잠금 유격·부하·탈조를 측정해야 한다. 이후 지지 전환 수를 줄이는 수열 선택, 검증된 가감속·정착 시간 조정, 하드웨어 강성 개선을 평가한다. 웹 배속4배는 이 성능 개선의 실물 증거가 아니다.

## 12. 제작과 시운전 계획

제작 안내서 첫 장에서 P/J 출력품, B 구매품, K 사진 키트 재사용품, M 가공품을 구분한다. 이후 시험편→프레임→코어/큐브→핀/베어링→서보/링크→D축/잠금 막대→중심 정렬→12접점 배선→무부하 전기 시험→한 면씩 저하중 시험 순서로 조립한다. Rev D에서 바뀐 출력물은 P13/P29이며 종류·수량은33종93개를 유지한다.

완료 조건은 실제12접점 진단, 양 끝 모순·한쪽 미도달 시 STEP0, 수동30mm 왕복·4mm 잠금 삽입, 코어 강성·핀 체결, 부하별 탈조·전원/발열, 반복 섞기/풀이5회 기록이다. 맞춤층은 시험편과 전체 강성 시험에 통과해야 한다. 서보 끼임 힘의 상한을 보장할 검증된 장치가 필요하다.

## 13. 한계와 다음 과제

현재 로봇은 내부 상태를 추정해 제어하는 개방 루프 장치다. `SOLVED ok=1`은 내부 모델이 풀렸다는 뜻이며, 핀 미끄러짐·탈조·손으로 바꾼 상태는 직접 감지하지 못한다. 색 인식/스마트큐브/엔코더는 미구현 과제다.

회전·이송·탐색은 블로킹이므로 버튼/시리얼로 즉시 정지하는 구조가 아니다. 끝 센서는 회전 중 연속 감시하지 않는다. 구동 전원의 물리적 차단 수단과 실제 보드 시험이 필요하다. 초기 서보 위치도 측정하지 않으므로 최초 시운전은 큐브·링크를 분리해 진행한다.

이번 수정은 확인된 뒤집기 원리 오류, 스위치 몸체 간섭과 접점 판정 문제를 제거하고 소프트웨어 검증 범위를 넓혔다. 남은 우선 과제는 사점의 힘 제한, 실물 공차·강성·마찰·열·탈조 검증이며, 이를 마친 뒤 속도 목표와 사람의 임의 섞기 입력을 진행한다.
