# V4 조립 단순화 Rev B 이력

현재 제작 기준은 [Rev C 커밋 비교·통합 기록](BUILD_V4_MERGE_REVIEW.md)과 최신 PDF다.
아래는 a7f8bcd의 8 mm 막대/구동판 기준 이력이며 현재33종93개 통합판과 혼용하지 않는다.

기준은 병합 커밋 `d8c21f49c8be001da35f6dc10457c168cfa5b99a`다. 기존 V4의
측면 4헤드, 하부 중공 헤드, 승강 잠금 막대와 열린 상부를 유지한다.
모터/서보 수, 큐브 크기, 구동핀 위치, 서보 축, 링크36, 이송24/30 mm,
프레임621 mm, 프로파일 절단268/301.5 mm와 동작 코드는 그대로다.

## 바뀐 제작 작업

| 작업 | Rev A | Rev B |
|---|---|---|
| 일반/D 서보 받침 고정 | 전산봉4개+간격관4개/모듈, 길이와 평행도 맞춤 | 공통 P14 돌기를 P13에 끼우고 M5 세 곳 체결 |
| 별도 절단·길이 맞춤 | 전산봉20본, 간격관20본 | 제거 |
| 해당 연결의 낱개 수 | 봉20+너트40+와셔40+관20=120 | M5 나사15+와셔15+T너트15=45 |
| 서보용 패널 관통 홀 | 4개/패널, 총20개 | 제거 |
| 레일 위치 잡기 | 눈금으로 좌우/앞끝 정렬 | 양쪽 턱과 앞 멈춤 턱에 놓기 |
| 레일 공급사별 첫 홀 차이 | 고정 원형 홀 | 폭3.4/길이14 장공7개 |
| 막대 가이드 고정 | M4×60 관통+너트 | 금속판 뒤에서 M4×12→인서트 |
| 막대 스위치 받침 고정 | M3×80 관통+너트 | 금속판 뒤에서 M3×12→인서트 |

숫자75개 감소는 서보 받침과 프레임 사이 연결만 비교한 것이다. 출력은 여전히
32종93개(지그·시험편 포함)이며 코어/허브/가이드의 금속 인서트는 필요하다.

## 세 곳 고정하는 받침

![서보 받침의 세 체결 위치](images/v4_manual/mount_detail.png)

그림은 고정부를 확대하려고 프로파일·레일·P13 일부를 잘랐으며 서보와 캡을
생략했다. 표시된 빨간 부품은 고정 볼트의 머리와 와셔다.

1. P13 뒷면을 2060 넓은 면에 밀착하고 기존 M5 네 개로 고정한다.
2. 레일을 좌우 턱 사이에 놓아 앞 멈춤 턱에 민다. 처음/끝 나사를 가조임한 뒤
   블록이 자유롭게 미끄러지는지 확인하고 일곱 나사를 조인다.
3. 서보를 넣은 P14의 한쪽 돌기를 P13 포켓에 넣는다. 아래 발과 P13,
   위 플랜지와 2060의 두 면이 동시에 밀착해야 한다.
4. 아래 F25 한 개를 먼저 손으로 물린다. 위 F11 두 개를 번갈아 조이고 아래를
   마무리한다. 측면4개와 D 모두 같은 부품과 조임 순서다.

모든 위치는 모듈 국소 좌표다. 위 두 M5 중심은 `(x,z)=(±20,239)`, 아래는
`(-20,171)`이다. 아래는 3T 발+6T 지지대+와셔약1을 지나므로 M5×16,
위는6T+와셔약1이므로 M5×12다. 실제 T너트 두께와 슬롯 바닥 여유를 확인한다.
아래 볼트 머리/와셔는 Ø8.5/Ø10 외형으로 이송 간섭을 검사한다.

위 두 점의 간격40 mm와 아래 점까지의 거리68 mm가 지지 삼각형을 만든다.
서보의 반력은 출력 크래들→세 체결면→2060으로 전달된다. 합판을 긴 봉으로
당겨 서보 위치를 결정하던 연결을 없앴다. 포켓의 돌기는 조립 위치만 정하며
하중 지지·강도 보증을 돌기에 의존하지 않는다.

## 정렬 여유와 조립 접근

- 레일 폭12에 대해 턱 안쪽 간격12.4: 한쪽0.2 여유. 턱 돌출1.5,
  블록 날개 아래와0.5 명목 여유를 둔다. 턱 끝은 z175로 크래들 아래를 피한다.
- 레일의 M3 나사는2060 중앙 슬롯의 T너트로 받는다. P13 뒤의 일반 너트를
  잡으려고 지지대를 다시 분해할 필요가 없다. 넓은 면 슬롯은 x=-20/0/+20이
  필요하다. 중앙 T너트는 P13/레일을 덮기 전에 배치하고 실제 카운터보어 깊이와
  물림 길이로 나사를 고른다. 끝삽입 너트라면 패널에 프로파일 끝을 막기 전에 넣는다.
- 레일만 z4.5..184.5로0.5 앞당겼다. 기존 뒤끝185는 서보 몸체 앞끝184.95와
  0.05 겹쳤다. 블록·캐리지·구동축 위치는 유지하고 몸체와0.45 명목 여유를 만든다.
- 서보 크래들과 캡의 겹침을 없애고 X방향0.15 틈을 둔다. P13 및 레일 끝과
  겹치던 크래들 재료도 제거했다. 서보 몸체를 볼트로 압착해 오차를 흡수하지 않는다.
- 위치 결정 돌기16×4×돌출0.8에 포켓16.4×4.4×깊이1.0을 사용한다.
  기본 여유는 한쪽0.2/깊이0.2다. 출력 버 때문에 걸리면 돌기만 억지로 누르지 않는다.
- P23 네 M4 인서트와 P29 두 M3 인서트는 금속판에 붙이기 전에 열삽입한다.
  P29 가로 팔은6→8 mm로 두껍게 해 인서트 주변 최소 벽을0.7→1.7 mm로 늘렸다.
  M04 뒤에서 나사를 넣으므로 D2060에 최종 고정하기 전에 조립한다.
- 인서트 뒤에는 M4 나사용 Ø4.3, M3 나사용 Ø3.4의 막힌 도피공을 둔다.
  6T 금속판+약1T 와셔 뒤로5 mm 들어오는12 mm 나사의 끝도 플라스틱에
  박히지 않도록 했다. 실제 인서트·와셔 길이는 조립 전에 대조한다.

## 교체·출력·구매

새로 출력할 대상은 P13/P14/P15/P23/P25/P26/P29다. 기존 번호와 파일명을
유지하므로 Rev A와 섞이지 않게 이전 파일은 별도 보관한다. 처음 제작하면
최신 PDF의 전체 수량을 따른다. 이미 가공한 Rev A 패널의 불필요한 Ø3.6 홀은
위치를 정하는 데 쓰지 않으며, 새 패널에는 뚫지 않는다.

P14는 국소-X면을 베드에 두고 열린 서보 삽입면이 위를 향하도록 슬라이서에서
검토한다. P13은 넓은 y=-57면을 베드에 둔다. 기준면을 서포트 위에 인쇄하거나
STL 전체 배율로 공차를 맞추지 않는다. 실제 구매 서보 외형을 먼저 대조한다.
이 방향의 P13 바닥 외곽은60×190, P14는31×82/출력 높이60 mm다.
두 부품을 분리해 일반적인220 mm 베드에서 배치와 개별 교체가 가능하게 했다.

체결표 F17/F18은 수량0이다. F11은32세트, 새 F25는5세트, M3 인서트69개,
M4 인서트14개다. F21/F24는 각각 M4×12/M3×12로 바뀐다. 여분은 별도다.

## 검증 범위와 실물 확인

기하 검사 결과는 `mechanical_checks.json`, `assembly_kit/kit_checks.json`,
메시/PDF 검사는 `mesh_checks.json`/`pdf_checks.json`에 기록한다. 본체 검사는
큐브36회전 표본, 뒤집기13표본, 모듈3자세를 포함한다. 보강 검사는 프레임3자세,
막대 받침3위치, 두 종류 모듈의 크랭크0~180°/15° 간격, 고정부끼리의 맞댐,
서보/레일/블록과 새 M5 볼트 머리·와셔의 명목 간섭을 검사한다.

최종 나사 도피공 확대는 BRep 차집합으로 P23/P29 모두 추가 체적0을 확인했다
(제거 체적119.38/58.39 mm³). 이 재료 제거는 기존 전체 운동 검사의 간섭 없음
판정을 보존한다. 다른 본체27종 STL은 전체 검사 시점과 바이트가 같으며,
최종 도피공의 M4/M3 나사 끝 통과·막대 이동과32종 메시를 별도로 확인한다.

최종 결과: 본체 실패0, 보강45개 검사 그룹 실패0, 출력32종93개 메시 통과,
PDF40쪽/첫 장60개 번호/40개 북마크/한국어 글꼴 포함/텍스트 경계 잘림0.
시뮬레이터의28개 STL과 파라미터도 최종 CAD 파일과 일치한다.

실물 출력·부하·수명 시험은 아직 하지 않았다. PETG 크리프, 인서트 뽑힘,
실제 서보 귀/케이블/혼·스위치 레버, 제조 오차를 모두 입체 모델로 확인한 것은
아니다. 한 모듈을 먼저 출력하고 무부하20회 뒤 기준면의 들뜸·균열·나사 풀림을
확인한다. 서보 몸체를 손으로 비틀 때 받침이 움직이거나 인서트가 들리면 운전하지 않는다.

핀/소켓의 한 방향 약0.60° 유격, 사각 잠금 약2.94°의 명목 유격과 가운데 층이
마찰로 따라오는 뒤집기 가정은 이번 변경으로 해결되지 않는다. 큐브 중심 정렬,
서보 혼 각도, 핀 깊이, 스위치 작동점과 실제 반복 오차는 PDF 순서로 확인해야 한다.

재생성 순서는 `models/robot_v4/assembly_kit/README.md`와 상세 PDF에 있다. `tools/package_robot_v4.py`는
본체·보강·메시·PDF 검사 통과 후 배포 ZIP과 SHA256 목록을 만든다.
