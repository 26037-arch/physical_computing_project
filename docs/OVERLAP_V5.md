# V5 겹침 점검 (2026-11-15)

3D 제작 설명서(`v5/sim/build.html`)의 장면을 그대로 읽어, 부품끼리 파고드는 곳이 있는지 본 기록이다.
출력 부품끼리의 정밀 검사(BRep)는 `tools/check_robot_v5_cad.py` 가 원본이고, 이 점검은 거기에 없는
**구매품 실제 외형 · 전자부 배치 · 케이블 길 · 끼워 넣는 경로**를 더한다.

## 실행

```
node tools/check_overlap_v5.js            # 결과 → models/robot_v5/overlap_checks.json, 겹치면 종료코드 1
node tools/check_overlap_v5.js --all      # 선끼리 겹쳐 그려진 곳까지 출력
node tools/check_overlap_v5.js --shots    # 단계별 화면 → docs/images/v5_build3d/step_NN.png
```

Chrome 또는 Edge 가 필요하다 (`CHROME_PATH` 로 지정 가능, 추가 패키지 없음). 화면에서는 설명서 아래쪽
**겹침 점검** 버튼이 같은 검사를 돌리고, 결과 줄을 누르면 그 자세로 가서 겹친 곳을 빨간 점으로 보여 준다.

## 방법

- 물체 A 의 겉면에서 0.15 mm 안으로 들인 표본점(간격 약 2 mm, 꼭짓점·변 포함)이 물체 B 안에 0.1 mm 넘게
  들어가 있으면 겹침이다. 안팎은 닫힌 삼각형 면에 광선 두 개를 쏴 교차 횟수의 홀짝으로 가린다.
  맞닿기만 한 면과 0.25 mm 보다 얕은 끼워 맞춤은 겹침으로 세지 않는다.
- 케이블·점퍼선은 곡선을 반지름 r 인 줄로 본다 (양 끝 2 mm 는 꽂히는 자리라 뺀다).
- 본 자세 411개: 완성 자세, 후드 0~120° (5°), 리프터 0~66 mm (3 mm, 후드 90°), 컵 0~90° (7.5°, 후드 OPEN·CLOSE),
  단계 ①~⑰ 의 조립 진행 0~100 % (5 %).
- 뺀 것: 나사·볼트·핀·고무발, 원형 혼, 실리콘 패드, 큐브 스티커 (일부러 물리거나 표시일 뿐인 것).
  조립 경로는 단단한 것끼리만 본다 (선·케이블은 손으로 비켜 놓을 수 있다).
- 반례 확인: 브레드보드를 로봇 쪽으로 60 mm, 커패시터를 두 칸, SG90 을 1 mm 옮기면 각각 겹침으로 잡힌다
  (깊이 1.1 / 2.6 / 1.1 mm).

## 결과

물체 59개 · 자세 411개 · 쌍 검사 17,917회.

| 항목 | 결과 |
|---|---|
| 완성 자세·구동 범위에서 부품끼리 겹침 | 0건 |
| 조립 경로(끼우는 방향)에서 부품끼리 겹침 | 0건 |
| 케이블·점퍼선이 부품을 지나감 | 0건 |
| 선끼리 겹쳐 그려진 곳 (참고) | 15쌍, 최대 1.3 mm |
| 의도된 끼워 맞춤 (제외) | 1쌍 — 컵을 돌릴 때 허브 D 구멍 ↔ 모터 축 0.6 mm. 실제 축은 컵과 함께 돌지만 모델의 축은 몸통과 한 덩어리라 생기는 차이다 |

선끼리 겹친 15쌍은 휘는 선을 그린 곡선이 서로 스친 것이다 (같은 열에 모인 서보 전원선, 모터 4선 묶음 등).
실물에서는 선이 비켜 가므로 조립에 영향이 없다.

## 점검하면서 고친 것

처음 돌렸을 때 나온 8건과 조치:

| 찾은 곳 | 깊이 | 조치 |
|---|---|---|
| ⑥ 리프터가 비스듬히 들어오며 컵 판을 지남 | 3.1 mm | 끼우는 방향을 **컵 바닥에 수직(곧게 위에서)** 으로 바꿈. 설명에 "기울여 넣으면 갈고리가 컵 판에 걸린다" 추가 |
| ⑦ 링크가 뒤에서 들어오며 높은 타워를 지남 | 3.9 mm | **위에서 곧게** 내려 넣는 것으로 바꿈 |
| 모터 케이블이 베이스 뒤 데크(두께 3.7 mm)를 뚫고 책상 아래로 감 | 2.3 / 1.6 mm | 뒷벽 창 → 데크 **위** → 데크 끝에서 책상으로 내려오는 길로 바꿈 |
| MG996R 케이블이 책상 아래로 처짐 | 1.0 mm | 내려오는 구간에 점을 더해 책상 위에 눕힘 |
| 모터 선(a7)이 옆 점퍼(a6)의 하우징을 지남 | 0.3 mm | 하우징 없는 선은 하우징 높이(10.6 mm) 위까지 곧게 올라간 뒤 휘게 함 |
| ⑬ 버튼이 내려오며 머리 위 점퍼선(D2→j11)을 스침 | 0.3 mm | 조립 경로에서 선은 검사에서 뺌 (손으로 비켜 놓는다) |
| 컵 회전 때 허브 ↔ 모터 축 | 0.6 mm | 모델 차이 — 위 표의 "의도된 끼워 맞춤" 으로 분류 |

앞의 두 건은 설명서가 실제로 들어가지 않는 방향을 그리고 있던 것이고, 나머지는 그림(케이블 길)의 문제였다.
출력 부품의 치수는 바꾸지 않았다.

## 한계

- 표본 간격 약 2 mm 와 띄엄띄엄한 자세의 검사다. 연속 운동의 증명이 아니며, 2 mm 보다 좁고 얕은 겹침은 놓칠 수 있다.
- 구매품은 참고 모델이다. SG90·MG996R 의 귀 높이 등은 실측 전 값이다 (`docs/KIT_PARTS.md`).
- 전자부를 놓은 자리와 케이블이 지나가는 길은 예시다. 실물을 다른 자리에 놓으면 이 결과는 그 자리를 보증하지 않는다.
- 뒤집히는 동안의 큐브 궤적은 보지 않는다 (`check_robot_v5_cad.py` 의 `d_flip_cube_65p1_clear` 가 본다).
- 강도·마찰·백래시는 보지 않는다.
