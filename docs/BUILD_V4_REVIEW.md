# robot_v4 제작 보강 Rev A 검토 기록

기준 커밋: `b37de3e9` (robot_v4 Draft). 문서 날짜: 2026-10-24 (한국 시간).

## 제공 결과

- 한국어 PDF 39페이지. 첫 장 A2 가로, 이후 A4. 첫 장 부품 번호60개, 출력/지그/구매/사진 키트/가공 재료 구분.
- 출력32종93개(지그·시험편 포함). P01~P28은 본체89개, P29는1개, J01~J03은3개.
- 프레임을 포함한 조립 STEP, 판재 DXF6개, 부품별 STL/STEP, 조달·체결 CSV.

## 구조 변경과 이유

- 5개 모듈을 묶는 개방 상부 합판/2060 프레임과 금속 앵글16개 추가. 독립 모듈 위치를 공통 기준면에 정렬한다.
- 서보를 크래들·분리 캡·전산봉·금속 간격관으로 포획. 실제 금속 혼에 크랭크를 M2 두 개로 연결한다.
- 후퇴 캐리지와 새 크래들의 충돌을 피하도록 앞 체결 귀를 옮기고, 프로파일 앞2 mm를 비워 R/D 끝 충돌을 없앴다.
- D 베어링 집에 캐리지 체결 홀·인서트 자리, 허브에 OD32 원통 보강을 추가했다.
- 앞/뒤 추력 지지와 금속 분할 링으로 회전축 이탈을 막는다.
- 잠금 가이드를 금속6T 지지판에 네 볼트로 연결하고, 막대 캐리지와 스위치 고정 방법을 구체화했다.
- 사각 포켓이 없애 버린 U/D 코어 인서트 자리를 안쪽에 복구했다.
- 막대 끝을 -23.8로 조절해 삽입2.7/바닥 여유0.3을 확보하고, 중공축 ID12.5로 대각 여유0.59를 확보했다.
- 행정24/30, 서보축 위치와 펌웨어 명령/운동 절차는 유지한다. 시뮬레이터는 실제 direct/hollow STL과 새 오프셋을 사용한다.

## 검증

- 본체: `mechanical_checks.json` passed=True, failure_count=0. 큐브36회전 표본, 뒤집기13표본, 모듈3자세, 막대/축·가이드·이송 기구 검사.
- 보강: `kit_checks.json` passed=True, failure_count=0. 프레임/로봇3자세, 막대 받침3위치, 두 헤드의 크랭크15도 간격 표본.
- 출력 메시: `mesh_checks.json` passed=True, 32종. 모든 에지에 두 삼각형, 양의 체적, BOM 파일명 대응 확인.
- 서보 크래들에서 선으로만 닿던 연결을 면으로 겹치도록 수정해 비다양체 메시를 제거했다.
- 크랭크의 혼 체결 홀도 본체와 함께 강체 회전함을 두 반경의45/90/180도에서 확인했다.
- Python 문법, Node 문법, 소스 파일 공백 검사 통과. STEP 내 OCC 생성 포맷의 공백은 소스 검사 대상에서 제외했다.
- PDF 39페이지·60개 번호·39개 북마크, 텍스트 경계 잘림 없음, 한국어 글꼴 포함 확인. 첫 장과 조립/가공/출처 페이지를 직접 열어 확인했다.
- Linux OCC의 native thread를 fork한 작업자 정지를 피하도록 본체 검사기의 ProcessPool 시작 방식을 spawn으로 수정했다.

## 실물에서 남은 조건

실물 출력·조립·부하·열 시험은 하지 않았다. 구매품은 설치 외형이며 실제 슬롯·혼·스위치 레버·볼트 머리·케이블을 전부 모델링하지 않았다. 기본 Ø3.4/Ø3 구동핀은 약0.60도 한 방향 유격, 8.4/8 사각 결합은 약2.94도 여유를 가질 수 있어0.5도 목표를 기본 CAD만으로 보장하지 않는다. 마찰로 가운데 층이 따라오는 뒤집기도 실물 검증이 필요하다. 불합격 시 잠금/뒤집기 구조의 추가 설계가 필요하며 자동 풀이 완료를 주장하지 않는다. PDF에 시험편→손회전→한 모듈→이송→한 면→뒤집기 순서와 실물 합격표를 제시했다.
