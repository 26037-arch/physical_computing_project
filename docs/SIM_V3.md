# V3 시뮬레이터 반영

2026-10-23. `sim/index.html`이 이제 V3 기구를 표시한다.

- 중앙 Ø6 고정축과 분할 코어는 장면의 고정부에 속한다. 면 회전 피벗에 포함되지 않는다.
- F/B 헤드는 V3 중공축, 6001 하우징, 60 mm 옆으로 옮긴 모터와 40T:40T 벨트를 사용한다.
- 회전축의 풀리는 중심축에서, 모터의 풀리는 옮겨진 모터축에서 각각 같은 각도로 회전한다. 모터 몸체/벨트 전체를 함께 회전시키지 않는다.
- 매 수 작동 면 잠금핀은 주차 위치, 반대 면은 잠금 위치로 표시한다. 새 쌍 결합 → 잠금 → 기존 쌍 후퇴 → 작동 면 회전 순서다.
- 바깥 외장판은 그리지 않는다. 가장자리 프레임 12개와 모듈/중앙축용 지지보가 남는다. 지지보는 모듈이 화면에서 떠 보이지 않도록 프레임까지 연결한다.
- `바깥 프레임`, `중앙축·고정 코어`, `큐브 내부 보기`를 추가했다. 내부 보기는 큐브 몸체/스티커를 투명하게 해서 중앙축과 코어를 보여 준다.
- 큐브 조각과 헤드는 V3 CAD의 조립 좌표 STL을 사용한다. 출력 STL의 베드 회전을 V2 오프셋으로 되돌리는 방식은 쓰지 않는다.

외부 개방 프레임은 이전 판재 박스 CAD의 **시각화 변형**이다. 이 화면을 새 프레임의 절단/강도 검증 도면으로 사용하지 않는다. 실제 제작에는 BUILD_V3 문서와 STEP를 참고한다. 화면의 이송·잠금 전환은 설명용 자동 재생이며 실물 수동 조작의 경로·시간·접촉을 검증하지 않는다. 핀의 잠금/주차 상태는 전환해서 표시하며 손으로 핀을 빼고 끼우는 경로를 해석하지 않는다.

## 재생성

```powershell
python -m pip install -r tools/requirements-robot-v3.txt
python tools/export_sim_v3.py
# 또는 CAD Python을 명시:
node tools/embed_models.js --python C:\path\to\python.exe
node tools/test_sim_v3.js
node tools/serve.js
```

`sim/models.js`는 자동 생성 파일이다. V3 CAD를 바꾸면 `export_sim_v3.py`를 다시 실행한다. 이전 V2 임베딩 도구는 `embed_models_v2.js`로 보존했으며 현재 시뮬레이터에 사용하지 않는다.
