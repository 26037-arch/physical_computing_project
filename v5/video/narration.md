# 제출 영상 TTS 대본 (1분, 10줄) — v3

**만드는 법**: 한 줄당 음성 파일 하나. 이름은 `01.mp3` ~ `10.mp3` (wav도 됨). 목소리·속도는 10줄 모두 같게.
**목표 초**를 넘기면 영상이 1분을 넘는다. 넘치면 속도를 1.1배 정도로 올린다. 파일 앞뒤 무음은 렌더할 때 자동으로 잘린다.

|---|---|---|---|
